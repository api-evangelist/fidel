# Fidel API

> One API for linking bank cards to applications, globally. Fidel (Enigmatic Smile Ltd trading as Fidel API) is a card-linking / payments-data platform: connect Visa, Mastercard and Amex cards to an application via PCI-compliant SDKs, then receive enriched, real-time transaction records over webhooks. Founded 2015, UK. Available in the US, UK, Ireland, Canada, Sweden and UAE.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public catalog and repo artifacts; it is not published by Fidel.

## APIs
- [Fidel API (v1, Select Transactions & Cards)](https://reference.fidel.uk/reference/introduction): Base URL https://api.fidel.uk/v1/ — programs, cards, transactions, brands, locations, offers, webhooks.
- [Transaction Stream API (v2.0)](https://transaction-stream.fidel.uk/v2.0/reference/authentication): Newer transaction-stream surface.
